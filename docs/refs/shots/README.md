# Reference archive

Drop screenshots here. Any PNG/JPG under this folder is durable project
memory: name it, tell the agent, and it gets read, distilled into
`docs/refs/*.md`, and registered in `REGISTRY.md` — future sessions
re-read the pixels from disk instead of asking again.

Naming: `<flow>-<variant>.png` (e.g. `uber-home.png`, `plan-trip.png`,
`reserve-sheet.png`). One image per flow-state; variants get suffixes.
